# Časová spoušť

PWA pro časosběrné snímání fotoaparátem iPhonu (11 / 12, iOS 16.4+).
Funkce: poměr 3:2 / 16:9, blesk (svítilna), pokus o zámek AF, interval a počet/doba, export přes Sdílet, offline.

Nasazení: GitHub Pages (Settings → Pages → Deploy from branch → main / root).
Adresa: https://pankubahunana.github.io/Casova-spoust/
